# みる ちから（MieeL）

よむ・かく・かぞえる の もとに なる「みる ちから（視覚認知）」を、8つの あそびで そだてる アプリです（特別支援教育向け・iPad / iPhone）。

## できること（どれも 3レベル・まいかい ちがう もんだい）
- 🔍 **まちがい さがし**：2まいの えを くらべて ちがう ところを タッチ（いれかわる・きえる・むき・おおきさ）
- 🧩 **おなじ かたち**：おなじ むきの かたちを ぜんぶ さがす（まわした・うらがえした かたちと くらべる）
- ✏️ **てん つなぎ**：1・2・3（むずかしいは あいうえお）の じゅんに つなぐと えが でる
- 〰️ **せん たどり**：めで せんを たどって、どこに つくか こたえる（追視）
- 🔢 **かず さがし**：にて いる ものの なかから ぜんぶ みつける（走査）
- 🐞 **め で おう**：うごく てんとうむしを めで おい、⭐ に なったら タッチ
- 🌀 **めいろ**：ゆびで みちを たどって ゴールへ（5×5〜11×11、まいかい ちがう めいろ）
- 👤 **かげ あわせ**：かげ（シルエット）の かたちだけで あてる（むずかしいは にた なかまの なかから）
- ヒント（しばらく みつからない とき）、⭐ と きろく
- **A4 プリント**：まちがいさがし・おなじ かたち・てんつなぎ・せんたどり・かずさがし・めいろ・かげ あわせ（こたえ つきも。まいかい ちがう もんだい）
- 🏠 ボタンで いつでも さいしょへ（ゲーム ちゅうは ながおし）

きろくは この たんまつの なかだけに ほぞん し、インターネットには おくりません。
